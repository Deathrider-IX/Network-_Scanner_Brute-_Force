# 🔍 Auto Scan Nmap

> **A Simple Bash Scripting Scanning Command** - Automated network reconnaissance tool powered by Nmap

---

## 📖 Description

**Auto Scan Nmap** is a lightweight, user-friendly bash script designed to simplify network reconnaissance and vulnerability scanning. It automates common Nmap operations, allowing security professionals and network administrators to quickly scan networks, identify active hosts, discover open ports, and gather detailed service information without manually crafting complex Nmap commands.

This tool is ideal for:
- **Network Administrators** - Monitor and manage network infrastructure
- **Security Professionals** - Conduct authorized penetration testing and vulnerability assessments
- **DevOps Teams** - Verify network configurations and service availability
- **System Administrators** - Identify unauthorized devices and services on the network

The script abstracts away Nmap's complexity while retaining the power of professional-grade network scanning, making it accessible to both beginners and experienced users.

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Deathrider-IX/auto-scan-nmap.git

# Navigate to directory
cd auto-scan-nmap

# Run the script
./scan.sh
```

## 📋 Requirements

- Bash shell
- Nmap installed (`apt-get install nmap` or `brew install nmap`)
- Root/sudo privileges for network scanning
